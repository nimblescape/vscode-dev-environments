# Start Docker Desktop

**Start Docker** starts Docker Desktop with its documented commands and waits until it is ready.

At its first start, Docker Desktop shows its own dialogs once:

- the Docker Subscription Service Agreement, which you accept to use Docker Desktop,
- an optional sign-in to a Docker account (you can skip it),
- the recommended settings.

After that, Dev Environments starts Docker by itself whenever an environment needs it.

This step checks itself off when Docker answers.
