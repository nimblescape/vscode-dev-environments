# Install WSL 2

Docker Desktop on Windows runs Linux containers in WSL 2, the Windows Subsystem for Linux.

**Install WSL 2** first shows you the command. When you confirm it, the command runs in a terminal of VS Code, where you can follow it:

```
wsl --install
```

- Windows asks for administrator permission.
- Restart the computer afterwards. Then open this page again: this step checks itself off when `wsl --status` succeeds.

If WSL 2 is already installed, this step is already checked off.
